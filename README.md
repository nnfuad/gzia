# 🇧🇩 President Ziaur Rahman – Dynamic Interactive Tribute

> **A sleek, interactive, and 3D‑enhanced tribute page** celebrating the life, legacy, and leadership of **President Ziaur Rahman** (Bir Uttom), the 7th President of Bangladesh, visionary statesman, and founder of the Bangladesh Nationalist Party (BNP).

🔗 **Live Demo:** []  

---

## 🎯 Project Purpose

This project was **created for a poster presentation competition by AEB(Association of Engineers Bangladesh)** to demonstrate:

- Modern front‑end development techniques (HTML5, Tailwind CSS, custom CSS, JavaScript)
- Dynamic content generation, interactive UI components, and 3D animations
- Aesthetic & responsive design with glassmorphism, motion, and thematic storytelling
- How historical legacy can be presented through engaging digital media

The poster presentation highlights the fusion of **historical tribute** with **cutting‑edge web interactivity** – making learning about President Ziaur Rahman’s contributions both informative and visually captivating.

## ✨ Key Features

| Feature | Description |
|---------|-------------|
| 📖 **Dynamic Biography** | In‑depth life story, path to presidency, and 19‑Point Programme details |
| 🃏 **Shuffleable Dynamic Cards** | Achievements & milestones that reorder randomly on button click |
| 🎲 **Random Real‑Life Story Generator** | 8+ inspiring, lesser‑known anecdotes from Ziaur Rahman’s life |
| 💬 **Random Quote Generator** | Motivational quotes from President Zia |
| 🧊 **3D Rotating Cube** | Fully animated, interactive 3D object symbolizing his revolutionary spirit |
| 🖼️ **Historical Gallery** | Real images from Wikimedia (with fallback placeholders) |
| 🌙 **Glassmorphism & Modern UI** | Frosted glass panels, smooth shadows, and vibrant gold accents |
| 📱 **Fully Responsive** | Works flawlessly on desktop, tablet, and mobile devices |
| 🔁 **Smooth Scrolling & Navigation** | Sticky navbar with anchor links |

## 🧰 Technologies Used

- **HTML5** – Semantic markup, structure
- **Tailwind CSS** – Utility‑first styling for rapid layout
- **Custom CSS** – 3D animations, cube keyframes, scrollbar styling, glass effects, hover transitions
- **Vanilla JavaScript** – Dynamic card shuffling, random story/quote generators, DOM manipulation, image fallback handling
- **Font Awesome 6** – Iconography
- **Google Fonts (Inter)** – Modern, readable typography

## 📁 File Structure

```
president-zia-tribute/
│
├── index.html          # Main HTML file (dynamic, fully self‑contained)
├── style.css           # Custom CSS (3D cube, glassmorphism, animations, responsive tweaks)
├── script.js           # JavaScript (card shuffling, random story/quote, interactivity)
└── README.md           # Project documentation (this file)
```

> **Note:** The HTML file links Tailwind CSS via CDN; custom CSS and JS are separated for clean modularity.

## 🚀 How to Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/nnfuad/president-zia-tribute.git
   ```
2. **Navigate to the project folder**
   ```bash
   cd president-zia-tribute
   ```
3. **Open `index.html`** in any modern web browser (Chrome, Firefox, Edge, Safari)
   - No build steps, dependencies, or server required – pure static files.

Alternatively, use **Live Server** in VS Code for a better development experience.

## 🖼️ Poster Presentation Context

This repository was **originally built for a poster presentation competition** where the goal was to:

- Showcase a historical figure using immersive web design
- Combine educational content with interactive elements (random stories, 3D motion, dynamic cards)
- Demonstrate front‑end creativity, responsiveness, and user engagement
- Stand out among static poster designs with a **live, clickable digital experience**

Judges and viewers can interact with the page directly – clicking buttons, shuffling cards, generating stories, and viewing the rotating 3D cube – making it far more memorable than a traditional printed poster.
